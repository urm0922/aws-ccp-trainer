# AWS CCP Trainer

AWS Certified Cloud Practitioner向けのオリジナル問題演習アプリです。実際の過去問やダンプは使用していません。

## 初期版の機能

- 1問ずつの問題演習と選択肢別解説
- ブラウザへの回答履歴保存
- 間違えた問題だけの復習
- お気に入り問題
- 分野別正答率
- 65問・90分の本番模試と60問短縮模試
- 択一選択・複数選択、模試中は解答を非表示
- 模試スコア推移グラフと分野別分析
- 問題の公開状態・難易度・根拠・確認日を扱う管理画面
- 約25分で4分野の大枠を学ぶ「最短インプット」教材
- 解説画面の選択肢別用語メモ
- レスポンシブ表示
